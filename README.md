# Python Journey

**Goal: become proficient with Python** by writing a lot of small, finished programs.

## Tracks

| Track | Folder | What |
|---|---|---|
| **Challenges** | `challenges/` | LeetCode-style problems: one file per problem, with tests |
| **Games** | `games/` | Small games, e.g. Pong and tic-tac-toe, one folder per game |
| **Scripts** | `scripts/` | Small scripts that do everyday tasks, e.g. rename files, sort downloads, back up a folder |

## Layout

```
challenges/   NNN_problem_name.py   (solution and tests in one file)
games/        <game>/               (one folder per game)
scripts/      <script>/             (one folder per script, with a short README)
progress.md   current position and daily log
```
